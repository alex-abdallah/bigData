# Données routières, 2012–2019

- `crash_data/` : huit fichiers annuels décrivant les accidents.
- `units_data/` : huit fichiers annuels décrivant les unités impliquées.
- `empreintes.json` : SHA-256 des 16 CSV. Le notebook contrôle ces empreintes à chaque exécution.
- [Documentation des champs](metadata-for-road-crash.pdf).

Source : gouvernement d’Australie-Méridionale, [Data.SA](https://data.sa.gov.au/). Les CSV sont reproduits à l’identique depuis [l’instantané utilisé par Rakesh Nain](https://github.com/RakeshNain/Big-data-Analysis-of-Road-Crash-Data-using-PySpark-with-PySpark-Tutorial/tree/dab8e6466747903bf1e5bd21ce63fea31bfb6dcc).
