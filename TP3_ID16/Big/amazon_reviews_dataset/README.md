# Données Amazon Reviews Polarity

Les onze fichiers `train-01.csv.gz` à `train-11.csv.gz` forment l’ensemble d’apprentissage de 3,6 millions d’avis. `test.csv.gz` contient les 400 000 avis de test. Spark lit ces fichiers directement, en conservant le découpage officiel.

[CSV d’origine sur Kaggle](https://www.kaggle.com/datasets/yacharki/amazon-reviews-for-sa-binary-negative-positive-csv/data)
